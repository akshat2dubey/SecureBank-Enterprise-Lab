# Stage 1 – Network Traffic Analyzer

✅ Completed foundation — the analyzer is built, tested, and wired into the
lab's integration contract. It will grow when Stage 7 (SIEM) consumes its
reports.

**Mission (Stage 1 of the SecureBank Enterprise Lab):** give SecureBank
*visibility* — can the bank see and understand what is happening on its
network?

## What it does

A passive Python/Scapy traffic analyzer that:

- Captures live traffic or reads PCAP files offline
- Collects **metadata only** — never stores or inspects packet payloads
- Identifies protocols (TCP, UDP, ICMP, ARP, DNS, IPv4/IPv6)
- Tracks source/destination addresses, ports, and flows
- Tracks TCP flags and generates traffic statistics
- Produces **schema-versioned JSON reports** (`traffic-report/1.0`, see
  `INTEGRATION.md` §6) for downstream stages
- Runs 3 **explainable heuristic detections** (SYN flood, port scan, plaintext
  legacy services) — a learning-grade alert layer, not an IDS
- Never crashes on malformed/truncated packets (counts them in
  `malformed_packets`)
- Bounds memory (O(MAX_UNIQUE)) for long captures

**Scope boundary:** a lab-scale user-space analyzer, deliberately not a
Zeek/Suricata replacement. Details and rationale in
`Project/outputs/README.md`.

## How it connects to the rest of the lab

| Consumes | Produces | Feeds |
|---|---|---|
| Lab traffic from Stage 2 (and later 4/6) | `traffic_report.json` (schema `traffic-report/1.0`) | Stage 7 SIEM, Stage 8 IR |

The **integration test** (`tests/integration_test.sh`) formally proves Stage 1
can observe traffic generated by Stage 2: it captures on the analyzer VM while
Kali runs Stage 2's traffic generator, then verifies the report contains the
expected protocols, the server's address, and SSH flows.

## Run

```bash
# install
python3 -m pip install -r requirements.txt

# live capture (authorized interface only)
sudo python3 Project/outputs/network_traffic_analyzer.py --interface eth0 --timeout 60 --json-out report.json

# offline analysis
python3 Project/outputs/network_traffic_analyzer.py --read-pcap incident.pcap --json-out report.json

# machine output for SIEM/cron (stdout stays parseable)
python3 Project/outputs/network_traffic_analyzer.py --interface eth0 --timeout 60 --json-only
```

## Test

```bash
python3 -m pip install pytest
python3 -m pytest tests/ -q                # unit suite (no live network needed)

# full ecosystem proof — on the analyzer VM, with Kali + server running
sudo ./tests/integration_test.sh eth0
```
