# Networking Basics

## What is a Computer Network?

A computer network is a collection of interconnected devices that communicate with each other to exchange data and share resources.
A network can also include subnetworks, or smaller subdivisions of the network. Subnetworking is how very large networks, such as those provided by ISPs, are able to manage thousands of IP addresses and connected devices.

## Why Do We Need Networking?

- Communication
- Resource Sharing
- Internet Access
- File Transfer
- Remote Access


## Types of Networks

- LAN (Local Area Network)
- MAN (Metropolitan Area Network)
- WAN (Wide Area Network)


## Real-world Example

A banking system consists of multiple branches connected over a secure WAN, where every ATM, employee workstation, database server, and customer-facing application communicates through the network.
